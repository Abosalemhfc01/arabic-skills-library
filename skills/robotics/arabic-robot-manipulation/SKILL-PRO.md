# التحكم بالأذرع الروبوتية والتعامل مع الأجسام

## الهدف
مساعدة المطور على بناء سير عمل التقاط ونقل ووضع الأجسام (Pick and Place)، من فهم نموذج الروبوت إلى اختبار الحركة في المحاكاة ثم الانتقال المنضبط إلى العتاد.

## متى تستخدم
- عند تصميم ذراع روبوتية أو محاكاتها.
- عند إعداد ROS 2 وMoveIt 2 وملفات URDF/Xacro.
- عند حساب التحويلات والإحداثيات والتخطيط لمسارات آمنة.
- عند تشخيص أخطاء الإمساك، التصادم، أو اختلاف الإطارات.

## تعليمات الوكيل
1. اسأل عن طراز الذراع، عدد درجات الحرية، نوع الماسك، نسخة ROS 2، ونوع المحاكاة.
2. ابدأ بالمحاكاة؛ لا تفترض أن الروبوت الحقيقي متصل.
3. ميّز بين إطار القاعدة وإطار الأداة وإطار الكاميرا؛ وثّق الوحدات بالمتر والراديان.
4. تحقق من حدود المفاصل، مدى الوصول، السرعة، التسارع، الاصطدامات، وحمولة الماسك.
5. استخدم تخطيط الحركة قبل التنفيذ، وتحقق من نتيجة التخطيط ومن نجاح التنفيذ بشكل مستقل.
6. لا تُرسل أوامر إلى عتاد فعلي دون موافقة صريحة، ومشغل بشري، وزر إيقاف طارئ واختبار مساحة العمل.
7. إذا نقصت مواصفات العتاد، أنشئ مثال محاكاة عام ولا تخترع إعدادات متحكم أو أسماء مفاصل.
8. اعرض خطوات قابلة للاختبار، وسجل الأخطاء وخطة التراجع.

## سير عمل Pick and Place
1. تحميل وصف الروبوت والماسِك وإطارات TF.
2. تحديد الجسم وموقعه في إطار مرجعي معروف.
3. تحديد وضعية اقتراب آمنة فوق الجسم.
4. تخطيط مسار الاقتراب والتحقق من التصادم.
5. تنفيذ الاقتراب في المحاكاة وإغلاق الماسك.
6. التحقق من نجاح الإمساك عبر حالة الماسك أو حساس مناسب.
7. رفع الجسم والتحرك إلى وضعية الإيداع.
8. فتح الماسك، التراجع، والتحقق من نجاح العملية.

## مثال Python تعليمي مستقل عن العتاد
هذا المثال يشرح منطق المهمة فقط؛ لا يتصل بـ ROS 2 ولا يحرك روبوتاً حقيقياً.

```python
class SimulatedArm:
    def __init__(self):
        self.gripping = False

    def move_to(self, pose):
        assert len(pose) == 3
        print("SIM MOVE:", pose)

    def grip(self, close):
        self.gripping = bool(close)
        print("SIM GRIP:", "closed" if close else "open")

def pick_and_place(robot, pick, place, clearance=0.10):
    if clearance <= 0:
        raise ValueError("clearance must be positive")
    above_pick = (pick[0], pick[1], pick[2] + clearance)
    above_place = (place[0], place[1], place[2] + clearance)
    robot.move_to(above_pick)
    robot.move_to(pick)
    robot.grip(True)
    robot.move_to(above_pick)
    robot.move_to(above_place)
    robot.move_to(place)
    robot.grip(False)
    robot.move_to(above_place)

if __name__ == "__main__":
    pick_and_place(SimulatedArm(), (0.2, 0.1, 0.05), (0.3, -0.1, 0.05))
```

**تنبيه:** المثال ليس مخطط حركة؛ لا يفحص التصادم أو قيود المفاصل أو الحمولات. لا تستخدمه مباشرة للتحكم بعتاد.

## تكامل ROS 2 وMoveIt 2
- ثبّت توزيعة ROS 2 المتوافقة مع نظام التشغيل وحزمة MoveIt 2 الموافقة لها.
- جهّز URDF/Xacro وSRDF وros2_control وإعدادات حدود المفاصل والمتحكمات.
- افحص TF وتطابق إطار التخطيط مع إطارات الأهداف.
- اختبر التخطيط والتنفيذ في RViz والمحاكاة قبل تفعيل أي متحكم فعلي.
- استخدم واجهات MoveIt 2 الرسمية المناسبة للإصدار المثبت؛ لا تفترض ثبات أسماء API بين الإصدارات.
- أضف جسم العمل إلى Planning Scene وحدّثه عند الإمساك والإفلات.

## اختبارات القبول
- هدف خارج مدى الذراع: رفض آمن.
- جسم عائق في المسار: فشل تخطيط واضح دون تنفيذ.
- فشل الإمساك: عدم متابعة النقل.
- انقطاع حالة المتحكم: توقف آمن.
- اختلاف إطار إحداثيات: اكتشاف الخطأ قبل الحركة.
